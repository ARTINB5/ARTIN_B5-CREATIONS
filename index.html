How I add a project (site owner)

This is a static GitHub Pages site, so visitors cannot upload files to it. To publish your own project, upload its image/video/file to this repository and add one item to the project list in index.html.

  1. Open the repository on GitHub and choose Add file → Upload files.
  2. Put media files in a folder named projects (create it by uploading a file into projects/).
  3. In index.html, find const PROJECTS = [ and add an entry using the example format shown there.
  4. Commit the changes. The gallery updates when GitHub Pages finishes publishing.

Keep personal details out of uploaded files. Ask a parent or guardian to review anything you share publicly.
